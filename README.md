# 滚珠魔方豆 · 微信小程序

一款三环换珠益智玩具的复刻与数字化实现：转动三个外圈和中心转子，让每个外圈内的珠子颜色统一。

## 目录结构

```
├── miniprogram/            # 微信小程序工程（appid=touristappid，可直接导入微信开发者工具）
│   ├── pages/index/        # 主页面（触摸交互、HUD、学习模式按钮）
│   └── utils/
│       ├── game.js         # 纯玩法逻辑（状态、转动、打乱、复原判定）
│       ├── geo.js          # 几何常量（盘半径 48mm，R=30，三圈圈心 120° 分布）
│       ├── draw.js         # Canvas 2D 盘面绘制
│       ├── core.js         # 交互控制器（拨圈跟手、转子吸附、动画队列、学习模式）
│       └── solver.js       # 自动求解器（贪心下降 + 交换子收尾，100% 可复原）
├── tools/build-preview.js  # 网页预览构建脚本（内联同一份 utils，单文件输出）
├── 预览/                    # 网页预览成品 + 效果截图
├── 图/                      # 结构示意图（SVG）
└── 滚珠魔方豆-玩法与设计说明.md  # 完整玩法与设计说明书（v3）
```

## 玩法规则（v3 规格）

- 盘面 3 个外圈 + 1 个中心转子，每圈 12 个珠位，全盘 36 颗珠（红/黄/蓝各 12）
- 每圈设 2 个闸口（相隔 60°），闸口处的珠子随中心转子转动而换圈
- 中心转子每转 120°（3 档），一次换珠 3 圈 × 各出 2 入 2 = 6 颗
- 外圈可 30°/档 自由转动，只改相位不换珠
- 目标：每个外圈内的珠子颜色一致

## 学习模式

开启后盘面锁定，点击「下一步」由求解器自动走一步（拨圈 + 换珠为一个完整动作），逐步演示直到复原；中途关闭可恢复手动拨动。

## 网页预览

直接用浏览器打开 `预览/滚珠魔方豆-网页预览.html` 即可试玩（与小程序共用同一份玩法代码）。

## 重新构建预览

```bash
node tools/build-preview.js
```
